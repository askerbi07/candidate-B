## 3. Код-ревью и исправление багов (Итерация 2)
**Ревьюер:** ERNIE-5.5-Flash-Preview (OpenRouter).
**Исполнитель:** DeepSeek v4.1 Flash (OpenCode).

После написания первой версии я прогнал код через независимого ИИ-ревьюера. Модель нашла несколько архитектурных проблем, которые были успешно исправлены:

**Замечания ревьюера (ERNIE-5.5-Flash):**
1. **Блокер:** Функция `build_contract` мутирует объект (побочный эффект). При повторном вызове аванс удвоится.
2. **Дыра в учете:** Если по отмененной работе был прямой платеж, он «исчезает» из отчета.
3. **Надежность:** Нет валидации входных файлов (KeyError, FileNotFoundError приводят к вылету).
4. **Тесты:** Отсутствуют unit-тесты на финансовую логику.
5. **Документация:** В README нет инструкции по запуску (только описание процесса).

**Что исправил DeepSeek v4.1 Flash:**
1. **Устранена мутация:** `build_contract` стала чистой функцией, возвращающей локальный словарь `advance_alloc`, не изменяя исходные объекты `Work`.
2. **Закрыта дыра с отменой:** Добавлен расчет `cancelled_direct`. Теперь прямые платежи по отмененным работам выводятся отдельной строкой «Списано по отмененной работе» и учитываются в общем итоге.
3. **Добавлена валидация:** Создан класс `DataError`. Теперь при отсутствии папки, неверных колонках или битых датах программа выдает понятное сообщение об ошибке и завершается с кодом 1, а не сыпет трейсбеком.
4. **Добавлены тесты:** Создан `test_main.py` (pytest). 4 теста проверяют контрольные цифры (D-1, D-2), отсутствие мутации и обработку ошибок. Все тесты пройдены (`4 passed`).
5. **Переписан README.md:** Теперь это чистая инструкция по запуску (Python 3.10+, команды, флаги `--date`, `--json`).
