# Отчёт по авансам и платежам по договорам

CLI-скрипт на Python: читает `data/contracts.csv`, `data/works.csv`, `data/payments.csv`
и на заданную отчётную дату строит отчёт по работам и итоги по каждому договору.

## Требования

- Python 3.10+ (используется синтаксис `date | None`; проверено на Python 3.14.3).
- Сторонние библиотеки для запуска не нужны.
- Для тестов нужен `pytest`.

## Запуск

```powershell
# отчёт на дату по умолчанию (2026-11-10)
python main.py

# отчёт на конкретную дату
python main.py --date 2026-11-10

# другая папка с CSV
python main.py --date 2026-11-10 --data-dir data

# JSON для автоматической обработки (деньги — строками)
python main.py --date 2026-11-10 --json
```

Параметры:

- `--date YYYY-MM-DD` — отчётная дата включительно, по умолчанию `2026-11-10`;
- `--data-dir PATH` — папка с CSV, по умолчанию `data/` рядом с `main.py`;
- `--json` — вывести отчёт в JSON вместо таблиц.

## Как считается

- Источник истины — даты (`paid_at`, `completed_at`, `refunded_at`), а не статусы.
- Платёж учитывается, если `paid_at <= отчётной даты` и он не возвращён на эту дату;
  платежи в очереди и возвращённые не уменьшают остаток.
- Суммы считаются в `decimal.Decimal`, округление `ROUND_HALF_UP` — только при выводе.
- Аванс без привязки к работе распределяется FIFO по выполненным работам;
  остаток показывается строкой «Нераспр. аванс».
- Отменённые работы не оплачиваются. Прямые платежи по ним не теряются:
  они выводятся отдельной строкой «Списано по отмененной работе» и входят в итог «Выплачено».
- Операции после отчётной даты выводятся справочно и в расчёт не входят.

Подробнее решения и допущения — в `DECISIONS.md`.

## Тесты

```powershell
python -m pytest -q
```

Ожидаемый результат:

```text
....                                                                     [100%]
4 passed
```

Тесты проверяют контрольные цифры D-1 и D-2, отсутствие мутации `Work`
в `build_contract`, отображение прямого платежа по отменённой работе
и понятные ошибки при отсутствии файла/колонки.

## Ошибки ввода

При отсутствии папки, файла или обязательной колонки скрипт завершается
с ненулевым кодом и понятным сообщением, например:

```text
Ошибка: не найден файл данных: C:\project\data\contracts.csv. Проверьте --data-dir.
```

Некорректная дата также приводит к ошибке с указанием ожидаемого формата `YYYY-MM-DD`.
