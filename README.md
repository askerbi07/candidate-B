# Отчёт по договорам и работам

Скрипт считает по каждому договору, сколько денег выплачено по работам на отчётную дату
и сколько осталось: прямые платежи закрывают работы напрямую, аванс распределяется FIFO
по выполненным работам. Все решения и их обоснование — в `DECISIONS.md`.

## Запуск

```bash
python main.py                          # отчётная дата по умолчанию 2026-11-10
python main.py --date 2026-12-01        # своя отчётная дата (YYYY-MM-DD)
python main.py --json                   # тот же отчёт в JSON (деньги — строками)
python main.py --data-dir D:\other\data # другая папка с CSV
```

Данные читаются из `data/` рядом со скриптом: `contracts.csv`, `works.csv`, `payments.csv`.
При ошибке входных данных программа пишет понятное сообщение в stderr и завершается с кодом 1.

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | точка входа, только запускает CLI |
| `models.py` | модели домена: Contract, Work, Payment, DataError |
| `services.py` | бизнес-логика: загрузка CSV, состояния по датам, FIFO-распределение аванса, сборка отчёта (консоль и JSON) |
| `cli.py` | argparse, вывод в консоль или json.dumps |
| `test_main.py` | pytest-тесты: контрольные цифры, FIFO, возвраты, after-date, ошибки ввода |

Зависимостей нет — только стандартная библиотека. Таблицы рисует собственный
`render_table` (services.py), поэтому `tabulate` не требуется.

## Проверка

```bash
python -m pytest test_main.py           # 11 тестов
python -m mypy --strict *.py            # строгая проверка типов
pip install -r requirements.txt         # только pytest и mypy для разработки
```
